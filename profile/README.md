## 🚀 Why Choose Albion ESP?

Tier filtering is the difference between a usable overlay and a wall of icons. This one shows only the resources you actually want, keeps players visible, and adds dungeon context for route decisions.

Each element toggles independently, so a gathering layout and a PvP layout can coexist.
